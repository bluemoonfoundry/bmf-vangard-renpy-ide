# Cross-File Symbol Index Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a project-wide, serializable index of Ren'Py symbol definitions and references (including Python variable reads and writes), built incrementally in the analysis worker from tree-sitter parse trees.

**Architecture:** Each block is parsed once into a plain-data `BlockContribution` (Ren'Py walk + Python walk over the injected trees, ranges mapped back to `.rpy` offsets); trees are freed immediately. A pure `resolveProjectIndex` merges contributions into a `ProjectSymbolIndex`. `updateProjectIndex` caches contributions by content hash so only changed blocks are re-parsed. The analysis worker attaches the index to `RenpyAnalysisResult` as an optional field next to the unchanged regex analysis.

**Tech Stack:** TypeScript, `web-tree-sitter` 0.24.7, `tree-sitter-renpy` (local grammar, WASM), vendored `tree-sitter-python.wasm`, Vitest + JSDOM.

**Spec:** `docs/superpowers/specs/2026-10-13-nms4.2-symbol-index-design.md`

## Global Constraints

- Imports use the `@/` alias, never `../` (CLAUDE.md).
- `src/types.ts` is the single source of truth for the index types.
- No `SyntaxNode`, `Tree` or other WASM object may be stored in or returned from any index data structure. Every parse is disposed with `disposeParsedBlock` in a `finally`.
- Symbol IDs are `${kind}:${qualifiedName}` (e.g. `label:start.sub`, `variable:persistent.seen_intro`, `image:eileen happy`).
- `SourcePoint.line` is 1-based; `column` and `offset` are 0-based UTF-16 code units (web-tree-sitter `startIndex`/`endIndex` are already code units; verified).
- The regex analysis result posted by the worker must be unchanged; `symbolIndex` and `indexError` are optional additions.
- Run a single test file with `npx vitest run <path>`; typecheck with `npm run typecheck`; lint with `npx eslint <paths>`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Non-ASCII text before a reference** (accented dialogue, emoji) — ranges must still slice exactly the name. Test added in Task 6.
2. **Overlapping index requests** (user keeps typing while the previous index build is still awaiting) — each result must reflect its own block list, never a mix. Test added in Task 8.
3. **Screen widget properties containing keywords** (`textbutton "Go" action SetVariable(...)`) — Python sees `action` inside an ERROR node; it must not appear as an unresolved variable. Test added in Task 5.
4. **Fixture files checked out with CRLF** (Windows `core.autocrlf`) — Python ranges after the first line of a `python:` block must still map to the right line and column. Test added in Task 6 (explicit CRLF) and implicitly by Task 7's fixture files.
5. **A block whose parse or extraction throws** — the rest of the project still indexes and the tree is still freed. Test added in Task 6.

```ts
/**
 * @file contentHash.ts
 * @description Fast 32-bit djb2 hash used to detect `.rpy` content changes
 * (analysis worker result cache, symbol-index contribution cache). Not
 * cryptographic.
 */

/**
 * Computes a 32-bit djb2 hash of a string.
 * @complexity O(n) where n = string length
 */
export function djb2(str: string): number {
  let hash = 5381;
  for (let i = 0; i < str.length; i++) {
    hash = ((hash << 5) + hash) + str.charCodeAt(i);
    hash |= 0; // keep 32-bit
  }
  return hash;
}
```

```ts
/**
 * @file sourceRange.ts
 * @description Converts tree-sitter offsets into the symbol index's plain
 * `SourceRange` data, and maps points inside an injected Python tree back to
 * offsets in the original `.rpy` source.
 *
 * Offsets are UTF-16 code units: web-tree-sitter's `startIndex`/`endIndex`
 * for a JS-string parse are already code units, so `content.slice(start, end)`
 * returns the node text.
 */
import type { SyntaxNode } from 'web-tree-sitter';
import type { SourcePoint, SourceRange } from '@/types';

export interface RangeContext {
  blockId: string;
  filePath: string;
  content: string;
  /** Offset of the first character of each line; lineStarts[0] === 0. */
  lineStarts: number[];
}

export function createRangeContext(blockId: string, filePath: string, content: string): RangeContext {
  const lineStarts = [0];
  for (let i = 0; i < content.length; i++) {
    if (content.charCodeAt(i) === 10) lineStarts.push(i + 1);
  }
  return { blockId, filePath, content, lineStarts };
}

/** 0-based index of the line containing `offset` (binary search). */
function lineIndexAt(ctx: RangeContext, offset: number): number {
  let lo = 0;
  let hi = ctx.lineStarts.length - 1;
  while (lo < hi) {
    const mid = (lo + hi + 1) >> 1;
    if (ctx.lineStarts[mid] <= offset) lo = mid;
    else hi = mid - 1;
  }
  return lo;
}

export function pointAt(ctx: RangeContext, offset: number): SourcePoint {
  const index = lineIndexAt(ctx, offset);
  return { line: index + 1, column: offset - ctx.lineStarts[index], offset };
}

export function rangeFromOffsets(ctx: RangeContext, start: number, end: number): SourceRange {
  return { blockId: ctx.blockId, filePath: ctx.filePath, start: pointAt(ctx, start), end: pointAt(ctx, end) };
}

export function rangeOfNode(ctx: RangeContext, node: SyntaxNode): SourceRange {
  return rangeFromOffsets(ctx, node.startIndex, node.endIndex);
}

/**
 * Maps a (row, column) point inside an injected Python tree back to an offset
 * in the original source. `parseBlock` slices the injection from
 * `injectionStart` and dedents every line after the first by up to the first
 * line's column, stripping spaces only — so row 0 is relative to
 * `injectionStart`, and row n > 0 is relative to that source line's start plus
 * however many leading spaces (at most the dedent column) were stripped.
 */
export function mapInjectionPoint(ctx: RangeContext, injectionStart: number, row: number, column: number): number {
  if (row === 0) return injectionStart + column;
  const firstLine = lineIndexAt(ctx, injectionStart);
  const dedentColumn = injectionStart - ctx.lineStarts[firstLine];
  const lineStart = ctx.lineStarts[firstLine + row];
  let stripped = 0;
  while (stripped < dedentColumn && ctx.content.charCodeAt(lineStart + stripped) === 32) stripped++;
  return lineStart + stripped + column;
}
```

```ts
/**
 * @file symbolNames.ts
 * @description Naming rules shared by the Ren'Py and Python walks and the
 * project resolver: symbol ids, local-label qualification, store-name
 * normalization, and names never recorded as variable references.
 */
import type { SymbolId, SymbolKind } from '@/types';

export function symbolId(kind: SymbolKind, name: string): SymbolId {
  return `${kind}:${name}`;
}

/**
 * Ren'Py local labels: `.sub` written after global label `start` is
 * `start.sub`. A fully dotted name is already qualified. A `.sub` with no
 * preceding global label is left as written (Ren'Py rejects it).
 */
export function qualifyLabel(written: string, currentGlobal: string | null): string {
  if (written.startsWith('.') && currentGlobal) return `${currentGlobal}${written}`;
  return written;
}

/**
 * Normalizes an attribute chain read from code. `store.x` is the store
 * variable `x`; `persistent.x` keeps its prefix; any other `a.b.c` refers to
 * the base `a`. `consumed` is how many chain parts the name covers, so callers
 * can build the source range.
 */
export function normalizeVariableName(parts: string[]): { name: string; consumed: number } {
  if (parts[0] === 'store' && parts.length > 1) {
    const inner = normalizeVariableName(parts.slice(1));
    return { name: inner.name, consumed: inner.consumed + 1 };
  }
  if (parts[0] === 'persistent' && parts.length > 1) {
    return { name: `persistent.${parts[1]}`, consumed: 2 };
  }
  return { name: parts[0], consumed: 1 };
}

  return written.startsWith('store.') ? written.slice('store.'.length) : written;
```

```ts
/**
 * @file renpyWalk.ts
 * @description Walks a tree-sitter-renpy tree in document order and extracts
 * the statement-level part of a block's symbol-index contribution:
 * definitions, references, menus and python blocks, plus label spans used to
 * find the enclosing label of Python injections. Python reads/writes inside
 * injected code are handled by pythonWalk.ts. Produces plain data only.
 */
import type { SyntaxNode } from 'web-tree-sitter';
import type {
  DefinitionKind, MenuInfo, PythonBlockInfo, ReferenceContext, ReferenceKind,
  SymbolDefinition, SymbolId, SymbolKind, SymbolReference,
} from '@/types';
import { rangeFromOffsets, rangeOfNode, type RangeContext } from '@/lib/tree-sitter/sourceRange';
import {
  isIgnoredName, normalizeDefinitionName, normalizeVariableName, qualifyLabel, symbolId,
} from '@/lib/tree-sitter/symbolNames';

export interface LabelSpan { id: SymbolId; start: number; end: number }

export interface RenpyWalkResult {
  definitions: SymbolDefinition[];
  references: SymbolReference[];
  menus: MenuInfo[];
  pythonBlocks: PythonBlockInfo[];
  labelSpans: LabelSpan[];
}

const CHARACTER_CALL_RE = /^Character\s*\(/;
/** `[name]`, `[name.attr]`, `[name!t]` — the name part only. */
const INTERPOLATION_RE = /\[([A-Za-z_][A-Za-z0-9_]*(?:\.[A-Za-z_][A-Za-z0-9_]*)*)/g;
const LEADING_NAME_RE = /^[A-Za-z_][A-Za-z0-9_]*/;
const NAME_RE = /[A-Za-z_][A-Za-z0-9_]*/g;

const SCREEN_REF_KIND: Record<string, ReferenceKind> = {
  show_screen_statement: 'show-screen',
  hide_screen_statement: 'hide-screen',
  call_screen_statement: 'call-screen',
};

const IMAGE_REF_KIND: Record<string, ReferenceKind> = {
  show_statement: 'show',
  scene_statement: 'scene',
  hide_statement: 'hide',
};

/** True when `node` has an anonymous keyword child, e.g. `jump expression x`. */
function hasKeyword(node: SyntaxNode, keyword: string): boolean {
  return node.children.some((child) => !child.isNamed && child.type === keyword);
}

function unquote(text: string): string {
  const quote = text[0];
  if (quote !== '"' && quote !== "'") return text;
  return text.length > 1 && text.endsWith(quote) ? text.slice(1, -1) : text.slice(1);
}

export function enclosingLabelFor(spans: LabelSpan[], offset: number): SymbolId | null {
  let best: LabelSpan | null = null;
  for (const span of spans) {
    if (span.start <= offset && offset < span.end && (!best || span.start > best.start)) best = span;
  }
  return best?.id ?? null;
}

export function walkRenpyTree(root: SyntaxNode, ctx: RangeContext): RenpyWalkResult {
  const out: RenpyWalkResult = { definitions: [], references: [], menus: [], pythonBlocks: [], labelSpans: [] };
  let currentGlobal: string | null = null;
  const labelStack: SymbolId[] = [];
  const enclosing = (): SymbolId | null => labelStack[labelStack.length - 1] ?? null;

  const define = (
    kind: SymbolKind, name: string, defKind: DefinitionKind, node: SyntaxNode,
    nameStart: number, nameEnd: number, detail?: string,
  ): void => {
    out.definitions.push({
      symbolId: symbolId(kind, name), kind, name, defKind,
      range: rangeOfNode(ctx, node),
      nameRange: rangeFromOffsets(ctx, nameStart, nameEnd),
      enclosingLabel: enclosing(),
      ...(detail !== undefined ? { detail } : {}),
    });
  };

  const reference = (
    kind: SymbolKind, name: string, refKind: ReferenceKind, start: number, end: number,
    context: ReferenceContext = 'statement', id: SymbolId | null = symbolId(kind, name),
  ): void => {
    out.references.push({
      symbolId: id, kind, name, refKind, context,
      range: rangeFromOffsets(ctx, start, end),
      enclosingLabel: enclosing(),
    });
  };

  const interpolations = (stringNode: SyntaxNode): void => {
    const text = stringNode.text;
    for (const match of text.matchAll(INTERPOLATION_RE)) {
      const index = match.index ?? 0;
      if (index > 0 && text[index - 1] === '[') continue; // `[[` is a literal bracket
      const { name } = normalizeVariableName(match[1].split('.'));
      if (isIgnoredName(name)) continue;
      const start = stringNode.startIndex + index + 1;
      reference('variable', name, 'read', start, start + match[1].length, 'interpolation');
    }
  };

  const visit = (node: SyntaxNode): void => {
    let pushedLabel = false;

    switch (node.type) {
      case 'label_statement': {
        const nameNode = node.childForFieldName('name');
        if (!nameNode) break;
        const written = nameNode.text;
        if (!written.includes('.')) currentGlobal = written;
        const name = qualifyLabel(written, currentGlobal);
        define('label', name, 'label', node, nameNode.startIndex, nameNode.endIndex, node.childForFieldName('parameters')?.text);
        const id = symbolId('label', name);
        out.labelSpans.push({ id, start: node.startIndex, end: node.endIndex });
        labelStack.push(id);
        pushedLabel = true;
        break;
      }

      case 'jump_statement':
      case 'call_statement': {
        const isCall = node.type === 'call_statement';
        const target = node.childForFieldName('target');
        if (target) {
          if (hasKeyword(node, 'expression')) {
            reference('label', target.text, isCall ? 'call-expression' : 'jump-expression',
              target.startIndex, target.endIndex, 'statement', null);
          } else {
            reference('label', qualifyLabel(target.text, currentGlobal), isCall ? 'call' : 'jump',
              target.startIndex, target.endIndex);
          }
        }
        const from = isCall ? node.childForFieldName('from_label') : null;
        if (from) define('label', qualifyLabel(from.text, currentGlobal), 'label', node, from.startIndex, from.endIndex);
        break;
      }

      case 'menu_statement': {
        const labelNode = node.childForFieldName('label');
        let labelId: SymbolId | null = null;
        if (labelNode) {
          define('label', labelNode.text, 'menu-label', node, labelNode.startIndex, labelNode.endIndex);
          labelId = symbolId('label', labelNode.text);
        }
        out.menus.push({
          range: rangeOfNode(ctx, node),
          labelId,
          enclosingLabel: enclosing(),
          choices: node.namedChildren
            .filter((child) => child.type === 'menu_choice')
            .map((choice) => {
              const text = choice.childForFieldName('text');
              // `condition` is a field on seq('if', expression), so the 'if' token carries it too.
              const condition = choice.childrenForFieldName('condition').find((c) => c.type === 'expression');
              return {
                text: text ? unquote(text.text) : '',
                condition: condition?.text ?? null,
                range: rangeOfNode(ctx, choice),
              };
            }),
        });
        break;
      }

      case 'menu_choice': {
        const text = node.childForFieldName('text');
        if (text) interpolations(text);
        break;
      }

      case 'screen_statement':
      case 'transform_statement':
      case 'style_statement': {
        const nameNode = node.childForFieldName('name');
        if (!nameNode) break;
        const kind: SymbolKind = node.type === 'screen_statement' ? 'screen'
          : node.type === 'transform_statement' ? 'transform' : 'style';
        const detail = kind === 'screen' ? node.childForFieldName('parameters')?.text
          : kind === 'style' ? node.childForFieldName('parent')?.text : undefined;
        define(kind, nameNode.text, kind, node, nameNode.startIndex, nameNode.endIndex, detail);
        break;
      }

      case 'image_statement': {
        const parts = node.childrenForFieldName('name');
        if (parts.length === 0) break;
        define('image', parts.map((p) => p.text).join(' '), 'image', node,
          parts[0].startIndex, parts[parts.length - 1].endIndex, node.childForFieldName('value')?.text);
        break;
      }

      case 'define_statement':
      case 'default_statement': {
        const nameNode = node.childForFieldName('name');
        if (!nameNode) break;
        const value = node.childForFieldName('value')?.text ?? '';
        const isDefine = node.type === 'define_statement';
        const kind: SymbolKind = isDefine && CHARACTER_CALL_RE.test(value) ? 'character' : 'variable';
        define(kind, normalizeDefinitionName(nameNode.text), isDefine ? 'define' : 'default', node,
          nameNode.startIndex, nameNode.endIndex, value);
        break;
      }

      case 'show_statement':
      case 'scene_statement':
      case 'hide_statement': {
        const parts = node.childrenForFieldName('image');
        if (parts.length === 0 || parts[0].text === 'expression') break;
        reference('image', parts.map((p) => p.text).join(' '), IMAGE_REF_KIND[node.type],
          parts[0].startIndex, parts[parts.length - 1].endIndex);
        break;
      }

      case 'show_screen_statement':
      case 'hide_screen_statement':
      case 'call_screen_statement': {
        const nameNode = node.childForFieldName('name');
        if (nameNode) reference('screen', nameNode.text, SCREEN_REF_KIND[node.type], nameNode.startIndex, nameNode.endIndex);
        break;
      }

      case 'screen_language_statement': {
        if (node.childForFieldName('widget_tag')?.text !== 'use') break;
        const property = node.childrenForFieldName('properties')[0];
        const expression = property?.namedChildren.find((c) => c.type === 'expression');
        const match = expression?.text.match(LEADING_NAME_RE);
        if (expression && match) {
          reference('screen', match[0], 'use', expression.startIndex, expression.startIndex + match[0].length);
        }
        break;
      }

      case 'say_statement': {
        const who = node.childForFieldName('character');
        if (who?.type === 'identifier') reference('character', who.text, 'speaker', who.startIndex, who.endIndex);
        const text = node.childForFieldName('text');
        if (text) interpolations(text);
        break;
      }

      case 'for_statement': {
        const variable = node.childForFieldName('variable');
        if (!variable) break;
        for (const match of variable.text.matchAll(NAME_RE)) {
          if (isIgnoredName(match[0])) continue;
          const start = variable.startIndex + (match.index ?? 0);
          reference('variable', match[0], 'write', start, start + match[0].length);
        }
        break;
      }

      case 'python_statement':
        out.pythonBlocks.push({ range: rangeOfNode(ctx, node), kind: 'python', priority: null });
        break;

      case 'init_python_statement': {
        const priority = node.childForFieldName('priority');
        out.pythonBlocks.push({
          range: rangeOfNode(ctx, node),
          kind: 'init-python',
          priority: priority ? Number(priority.text) : null,
        });
        break;
      }

      default:
        break;
    }

    for (const child of node.namedChildren) visit(child);
    if (pushedLabel) labelStack.pop();
  };

  visit(root);
  return out;
}
```

```ts
/**
 * @file pythonWalk.ts
 * @description Walks one injected tree-sitter-python tree and records store
 * variable reads and writes plus top-level `def`/`class` definitions, for the
 * symbol index. Points are relative to the injected span; blockContribution.ts
 * maps them back to `.rpy` offsets.
 *
 * Scoping (deliberately simple — see the spec's Non-Goals):
 * - The top level of a `$` line, a `python:` body or an injected expression is
 *   store scope: assignments are writes, other names are reads.
 * - `def`, `lambda`, comprehensions and class bodies open a local scope.
 *   Parameters and names bound inside are locals and are not recorded; other
 *   names are store reads. Inside a `def`, a write is recorded only for names
 *   declared `global`.
 * - Imported names, ignored names (symbolNames.ts) and anything inside an
 *   ERROR node are never recorded.
 */
import type { Point, SyntaxNode } from 'web-tree-sitter';
import { isIgnoredName, normalizeVariableName } from '@/lib/tree-sitter/symbolNames';

export interface PythonUse { name: string; refKind: 'read' | 'write'; start: Point; end: Point }

export interface PythonDef {
  kind: 'python-function' | 'python-class';
  name: string;
  start: Point;
  end: Point;
  nameStart: Point;
  nameEnd: Point;
}

export interface PythonWalkResult { uses: PythonUse[]; defs: PythonDef[] }

interface Scope {
  locals: Set<string>;
  globals: Set<string>;
  isStore: boolean;
  parent: Scope | null;
}

const COMPREHENSIONS = new Set(['list_comprehension', 'set_comprehension', 'dictionary_comprehension', 'generator_expression']);
const SCOPE_BOUNDARIES = new Set(['function_definition', 'class_definition', 'lambda', ...COMPREHENSIONS]);
const TARGET_CONTAINERS = new Set([
  'pattern_list', 'tuple_pattern', 'list_pattern', 'tuple', 'list', 'parenthesized_expression',
  'list_splat_pattern', 'expression_list',
]);
const IMPORTS = new Set(['import_statement', 'import_from_statement', 'future_import_statement']);

/** Identifier nodes bound by an assignment/for target (not attributes or subscripts). */
function boundIdentifiers(target: SyntaxNode): SyntaxNode[] {
  if (target.type === 'identifier') return [target];
  if (TARGET_CONTAINERS.has(target.type)) return target.namedChildren.flatMap(boundIdentifiers);
  return [];
}

/** Parameter names of a `parameters` or `lambda_parameters` node. */
function parameterNames(params: SyntaxNode): string[] {
  const names: string[] = [];
  for (const param of params.namedChildren) {
    if (param.type === 'identifier') {
      names.push(param.text);
    } else if (param.type === 'default_parameter' || param.type === 'typed_default_parameter') {
      const name = param.childForFieldName('name');
      if (name) names.push(name.text);
    } else {
      const first = param.namedChildren.find((c) => c.type === 'identifier');
      if (first) names.push(first.text);
    }
  }
  return names;
}

/** Names introduced by import statements anywhere in the tree. */
function importedNames(root: SyntaxNode): Set<string> {
  const names = new Set<string>();
  const visit = (node: SyntaxNode): void => {
    if (IMPORTS.has(node.type)) {
      for (const child of node.namedChildren) {
        if (child.type === 'aliased_import') {
          const alias = child.childForFieldName('alias');
          if (alias) names.add(alias.text);
        } else if (child.type === 'dotted_name' && node.childForFieldName('module_name')?.id !== child.id) {
          names.add(child.namedChildren[0]?.text ?? child.text);
        }
      }
      return;
    }
    node.namedChildren.forEach(visit);
  };
  visit(root);
  return names;
}

/** Collects the names a function/class/lambda/comprehension body binds locally, without entering nested scopes. */
function collectBindings(body: SyntaxNode, scope: Scope): void {
  const visit = (node: SyntaxNode): void => {
    switch (node.type) {
      case 'assignment':
      case 'augmented_assignment':
      case 'for_statement': {
        const left = node.childForFieldName('left');
        if (left) boundIdentifiers(left).forEach((id) => scope.locals.add(id.text));
        break;
      }
      case 'named_expression': {
        const name = node.childForFieldName('name');
        if (name) scope.locals.add(name.text);
        break;
      }
      case 'as_pattern_target':
        node.namedChildren.flatMap(boundIdentifiers).forEach((id) => scope.locals.add(id.text));
        break;
      case 'global_statement':
        node.namedChildren.filter((c) => c.type === 'identifier').forEach((id) => scope.globals.add(id.text));
        return;
      case 'function_definition':
      case 'class_definition': {
        const name = node.childForFieldName('name');
        if (name) scope.locals.add(name.text);
        return;
      }
      default:
        break;
    }
    if (SCOPE_BOUNDARIES.has(node.type)) return;
    node.namedChildren.forEach(visit);
  };
  body.namedChildren.forEach(visit);
}

export function walkPythonTree(root: SyntaxNode, options: { allowDefinitions: boolean }): PythonWalkResult {
  const result: PythonWalkResult = { uses: [], defs: [] };
  const storeScope: Scope = { locals: importedNames(root), globals: new Set(), isStore: true, parent: null };

  const isLocal = (name: string, scope: Scope): boolean => {
    for (let s: Scope | null = scope; s; s = s.parent) {
      if (s.isStore) return s.locals.has(name);
      if (s.globals.has(name)) return false;
      if (s.locals.has(name)) return true;
    }
    return false;
  };

  const push = (name: string, refKind: 'read' | 'write', first: SyntaxNode, last: SyntaxNode): void => {
    if (isIgnoredName(name)) return;
    result.uses.push({ name, refKind, start: first.startPosition, end: last.endPosition });
  };

  const readIdentifier = (id: SyntaxNode, scope: Scope): void => {
    if (!isLocal(id.text, scope)) push(id.text, 'read', id, id);
  };

  const writeIdentifier = (id: SyntaxNode, scope: Scope): void => {
    if (scope.isStore ? !scope.locals.has(id.text) : scope.globals.has(id.text)) push(id.text, 'write', id, id);
  };

  /** `a.b.c` — store./persistent. chains are their own variables; anything else reads its base. */
  const visitAttributeChain = (attribute: SyntaxNode, refKind: 'read' | 'write', scope: Scope): void => {
    const parts: SyntaxNode[] = [];
    let node: SyntaxNode = attribute;
    while (node.type === 'attribute') {
      const attr = node.childForFieldName('attribute');
      const object = node.childForFieldName('object');
      if (!attr || !object) return;
      parts.unshift(attr);
      node = object;
    }
    if (node.type !== 'identifier') {
      visit(node, scope); // e.g. f().x — visit the call
      return;
    }
    parts.unshift(node);
    const { name, consumed } = normalizeVariableName(parts.map((p) => p.text));
    if (consumed === 1) {
      readIdentifier(node, scope); // obj.attr (read or mutated) reads obj
      return;
    }
    push(name, refKind, parts[0], parts[consumed - 1]);
  };

  const visitTarget = (target: SyntaxNode, scope: Scope): void => {
    if (target.type === 'identifier') writeIdentifier(target, scope);
    else if (target.type === 'attribute') visitAttributeChain(target, 'write', scope);
    else if (TARGET_CONTAINERS.has(target.type)) target.namedChildren.forEach((c) => visitTarget(c, scope));
    else visit(target, scope); // subscript etc.: reads
  };

  const childScope = (parent: Scope): Scope => ({ locals: new Set(), globals: new Set(), isStore: false, parent });

  const pushDef = (kind: PythonDef['kind'], node: SyntaxNode, name: SyntaxNode): void => {
    result.defs.push({
      kind, name: name.text,
      start: node.startPosition, end: node.endPosition,
      nameStart: name.startPosition, nameEnd: name.endPosition,
    });
  };

  const visit = (node: SyntaxNode, scope: Scope): void => {
    switch (node.type) {
      case 'ERROR':
        return;
      case 'identifier':
        readIdentifier(node, scope);
        return;
      case 'attribute':
        visitAttributeChain(node, 'read', scope);
        return;
      case 'assignment':
      case 'augmented_assignment': {
        const right = node.childForFieldName('right');
        const type = node.childForFieldName('type');
        const left = node.childForFieldName('left');
        if (right) visit(right, scope);
        if (type) visit(type, scope);
        if (left) visitTarget(left, scope);
        return;
      }
      case 'for_statement': {
        const left = node.childForFieldName('left');
        if (left) visitTarget(left, scope);
        for (const child of node.namedChildren) if (child.id !== left?.id) visit(child, scope);
        return;
      }
      case 'named_expression': {
        const name = node.childForFieldName('name');
        const value = node.childForFieldName('value');
        if (value) visit(value, scope);
        if (name) visitTarget(name, scope);
        return;
      }
      case 'keyword_argument': {
        const value = node.childForFieldName('value');
        if (value) visit(value, scope);
        return;
      }
      case 'import_statement':
      case 'import_from_statement':
      case 'future_import_statement':
      case 'global_statement':
      case 'nonlocal_statement':
        return;
      case 'function_definition': {
        const name = node.childForFieldName('name');
        if (name && scope.isStore && options.allowDefinitions) pushDef('python-function', node, name);
        const fnScope = childScope(scope);
        const params = node.childForFieldName('parameters');
        if (params) {
          parameterNames(params).forEach((p) => fnScope.locals.add(p));
          // Default values are evaluated in the enclosing scope.
          for (const param of params.namedChildren) {
            const value = param.childForFieldName('value');
            if (value) visit(value, scope);
          }
        }
        const returnType = node.childForFieldName('return_type');
        if (returnType) visit(returnType, scope);
        const body = node.childForFieldName('body');
        if (body) {
          collectBindings(body, fnScope);
          visit(body, fnScope);
        }
        return;
      }
      case 'class_definition': {
        const name = node.childForFieldName('name');
        if (name && scope.isStore && options.allowDefinitions) pushDef('python-class', node, name);
        const superclasses = node.childForFieldName('superclasses');
        if (superclasses) visit(superclasses, scope);
        const body = node.childForFieldName('body');
        if (body) {
          const classScope = childScope(scope);
          collectBindings(body, classScope);
          visit(body, classScope);
        }
        return;
      }
      case 'lambda': {
        const lambdaScope = childScope(scope);
        const params = node.childForFieldName('parameters');
        if (params) parameterNames(params).forEach((p) => lambdaScope.locals.add(p));
        const body = node.childForFieldName('body');
        if (body) visit(body, lambdaScope);
        return;
      }
      default:
        break;
    }

    if (COMPREHENSIONS.has(node.type)) {
      const compScope = childScope(scope);
      for (const clause of node.namedChildren.filter((c) => c.type === 'for_in_clause')) {
        const left = clause.childForFieldName('left');
        if (left) boundIdentifiers(left).forEach((id) => compScope.locals.add(id.text));
      }
      for (const child of node.namedChildren) {
        if (child.type === 'for_in_clause') {
          const right = child.childForFieldName('right');
          if (right) visit(right, compScope);
        } else {
          visit(child, compScope);
        }
      }
      return;
    }

    for (const child of node.namedChildren) visit(child, scope);
  };

  visit(root, storeScope);
  return result;
}
```

```ts
/**
 * @file blockContribution.ts
 * @description Builds one block's plain-data contribution to the project
 * symbol index: parses the block, runs the Ren'Py and Python walks, maps
 * Python points back to `.rpy` offsets, and always frees the parse trees.
 * Never rejects: a parse or extraction failure yields an empty contribution
 * with `hasError: true` so one bad file can't sink the index.
 */
import type { Point, SyntaxNode } from 'web-tree-sitter';
import type { BlockContribution, ReferenceContext, SymbolDefinition, SymbolReference } from '@/types';
import { parseBlock, disposeParsedBlock, type ParsedBlock, type PythonInjection } from '@/lib/tree-sitter/parseBlock';
import { djb2 } from '@/lib/contentHash';
import { createRangeContext, mapInjectionPoint, rangeFromOffsets } from '@/lib/tree-sitter/sourceRange';
import { symbolId } from '@/lib/tree-sitter/symbolNames';
import { enclosingLabelFor, walkRenpyTree } from '@/lib/tree-sitter/renpyWalk';
import { walkPythonTree } from '@/lib/tree-sitter/pythonWalk';

export interface IndexBlock { id: string; filePath: string; content: string }

const CONDITION_PARENTS = new Set(['if_statement', 'elif_clause', 'while_statement', 'menu_choice']);

/** Where an injected Python fragment sits, from its injection kind and Ren'Py ancestors. */
export function injectionContext(root: SyntaxNode, injection: PythonInjection): ReferenceContext {
  if (injection.kind === 'python-block') return 'python-block';
  if (injection.kind === 'dollar-statement') return 'dollar';
  for (let node: SyntaxNode | null = root.descendantForIndex(injection.range[0], injection.range[1]); node; node = node.parent) {
    if (node.type === 'property' || node.type === 'screen_language_statement') return 'screen-expression';
    if (CONDITION_PARENTS.has(node.type)) return 'condition';
    if (node.type.startsWith('atl_')) return 'atl-expression';
  }
  return 'screen-expression';
}

/**
 * `use item_list(n)` is a screen-language property, so its whole text is
 * Python-injected; the leading name is the screen reference renpyWalk.ts
 * already records, not a variable read. Callers drop the use at (0, 0).
 */
export function isUseInjection(root: SyntaxNode, injection: PythonInjection): boolean {
  if (injection.kind !== 'screen-expression') return false;
  for (let node: SyntaxNode | null = root.descendantForIndex(injection.range[0], injection.range[1]); node; node = node.parent) {
    if (node.type === 'screen_language_statement') return node.childForFieldName('widget_tag')?.text === 'use';
  }
  return false;
}

const byOffset = (a: { range: { start: { offset: number } } }, b: { range: { start: { offset: number } } }) =>
  a.range.start.offset - b.range.start.offset;

export async function buildBlockContribution(block: IndexBlock): Promise<BlockContribution> {
  const contentHash = djb2(block.content);
  const empty = (): BlockContribution => ({
    blockId: block.id, filePath: block.filePath, contentHash, hasError: true,
    definitions: [], references: [], menus: [], pythonBlocks: [],
  });

  let parsed: ParsedBlock;
  try {
    parsed = await parseBlock(block.content);
  } catch {
    return empty();
  }

  try {
    const root = parsed.tree.rootNode;
    const ctx = createRangeContext(block.id, block.filePath, block.content);
    const renpy = walkRenpyTree(root, ctx);
    const definitions: SymbolDefinition[] = [...renpy.definitions];
    const references: SymbolReference[] = [...renpy.references];

    for (const injection of parsed.pythonInjections) {
      const injectionStart = injection.range[0];
      const context = injectionContext(root, injection);
      const enclosingLabel = enclosingLabelFor(renpy.labelSpans, injectionStart);
      const toOffset = (p: Point) => mapInjectionPoint(ctx, injectionStart, p.row, p.column);
      const python = walkPythonTree(injection.tree.rootNode, { allowDefinitions: context === 'python-block' });
      const skipLeadingName = isUseInjection(root, injection);

      for (const use of python.uses) {
        if (skipLeadingName && use.start.row === 0 && use.start.column === 0) continue;
        references.push({
          symbolId: symbolId('variable', use.name), kind: 'variable', name: use.name,
          refKind: use.refKind, context,
          range: rangeFromOffsets(ctx, toOffset(use.start), toOffset(use.end)),
          enclosingLabel,
        });
      }
      for (const def of python.defs) {
        definitions.push({
          symbolId: symbolId(def.kind, def.name), kind: def.kind, name: def.name,
          defKind: def.kind === 'python-function' ? 'def' : 'class',
          range: rangeFromOffsets(ctx, toOffset(def.start), toOffset(def.end)),
          nameRange: rangeFromOffsets(ctx, toOffset(def.nameStart), toOffset(def.nameEnd)),
          enclosingLabel,
        });
      }
    }

    definitions.sort(byOffset);
    references.sort(byOffset);
    return {
      blockId: block.id, filePath: block.filePath, contentHash,
      hasError: root.hasError,
      definitions, references, menus: renpy.menus, pythonBlocks: renpy.pythonBlocks,
    };
  } catch {
    return empty();
  } finally {
    disposeParsedBlock(parsed);
  }
}
```

`Array.prototype.sort` is stable, so the walk order is kept for equal offsets.

```ts
/**
 * @file projectIndex.ts
 * @description Merges per-block contributions into the project-wide symbol
 * index (`resolveProjectIndex`, pure and synchronous) and keeps contributions
 * cached by content hash so only changed blocks are re-parsed
 * (`updateProjectIndex`). See
 * docs/superpowers/specs/2026-10-13-nms4.2-symbol-index-design.md §3.
 */
import type {
  BlockContribution, IndexedSymbol, ProjectSymbolIndex, SourceRange, SymbolId, SymbolKind, SymbolReference,
} from '@/types';
import { symbolId } from '@/lib/tree-sitter/symbolNames';

const cmp = (a: string, b: string): number => (a < b ? -1 : a > b ? 1 : 0);

const compareRanges = (a: SourceRange, b: SourceRange): number =>
  cmp(a.filePath, b.filePath) || cmp(a.blockId, b.blockId) || a.start.offset - b.start.offset;

/** Read references to these kinds are tried in this order before falling back to a variable. */
const READ_RESOLUTION_ORDER: SymbolKind[] = ['python-function', 'python-class', 'character', 'variable'];

export function resolveProjectIndex(contributions: Map<string, BlockContribution>): ProjectSymbolIndex {
  const ordered = [...contributions.values()].sort((a, b) => cmp(a.filePath, b.filePath) || cmp(a.blockId, b.blockId));
  const definitions = ordered.flatMap((c) => c.definitions);
  const references = ordered.flatMap((c) => c.references);

  const symbols = new Map<SymbolId, IndexedSymbol>();
  const ensure = (id: SymbolId, kind: SymbolKind, name: string): IndexedSymbol => {
    let symbol = symbols.get(id);
    if (!symbol) {
      symbol = { id, kind, name, definitions: [], references: [] };
      symbols.set(id, symbol);
    }
    return symbol;
  };

  for (const definition of definitions) ensure(definition.symbolId, definition.kind, definition.name).definitions.push(definition);

  // Implicit definitions: the earliest write of a variable nothing defines.
  for (const ref of references) {
    if (ref.refKind !== 'write' || ref.kind !== 'variable' || ref.symbolId === null) continue;
    const existing = symbols.get(ref.symbolId);
    if (existing && existing.definitions.length > 0) continue;
    ensure(ref.symbolId, 'variable', ref.name).definitions.push({
      symbolId: ref.symbolId, kind: 'variable', name: ref.name,
      defKind: ref.context === 'python-block' ? 'python-assign' : 'implicit',
      range: ref.range, nameRange: ref.range, enclosingLabel: ref.enclosingLabel,
    });
  }

  // Images resolve by tag (first word) when there is no exact definition.
  const imagesByTag = new Map<string, IndexedSymbol[]>();
  for (const symbol of symbols.values()) {
    if (symbol.kind !== 'image') continue;
    const tag = symbol.name.split(' ')[0];
    imagesByTag.set(tag, [...(imagesByTag.get(tag) ?? []), symbol]);
  }
  for (const candidates of imagesByTag.values()) {
    candidates.sort((a, b) => a.name.length - b.name.length || cmp(a.name, b.name));
  }

  const resolve = (ref: SymbolReference): SymbolReference => {
    if (ref.symbolId === null || symbols.has(ref.symbolId)) {
      if (ref.kind !== 'variable' || ref.refKind !== 'read') return ref;
    }
    if (ref.kind === 'image') {
      const candidate = imagesByTag.get(ref.name.split(' ')[0])?.[0];
      return candidate ? { ...ref, symbolId: candidate.id } : ref;
    }
    if (ref.kind === 'variable' && ref.refKind === 'read') {
      for (const kind of READ_RESOLUTION_ORDER) {
        const id = symbolId(kind, ref.name);
        if (symbols.has(id)) return { ...ref, symbolId: id, kind };
      }
    }
    return ref;
  };

  const unresolved: SymbolReference[] = [];
  for (const ref of references) {
    const resolved = resolve(ref);
    if (resolved.symbolId === null) continue; // dynamic jump/call: not attached, not unresolved
    const symbol = symbols.get(resolved.symbolId);
    if (symbol) symbol.references.push(resolved);
    else unresolved.push(resolved);
  }

  for (const symbol of symbols.values()) {
    symbol.definitions.sort((a, b) => compareRanges(a.range, b.range));
    symbol.references.sort((a, b) => compareRanges(a.range, b.range));
  }
  unresolved.sort((a, b) => compareRanges(a.range, b.range));

  const sortedSymbols = new Map([...symbols.entries()].sort(([a], [b]) => cmp(a, b)));
  const duplicates = [...sortedSymbols.values()]
    .filter((s) => (s.kind === 'label' || s.kind === 'screen') && s.definitions.length > 1)
    .map((s) => s.id);

  return { symbols: sortedSymbols, unresolved, duplicates, contributions };
}
```

```ts
export interface ContributionCache { byBlockId: Map<string, BlockContribution> }

export function createContributionCache(): ContributionCache {
  return { byBlockId: new Map() };
}

export interface UpdateIndexDeps {
  build?: (block: IndexBlock) => Promise<BlockContribution>;
  init?: () => Promise<void>;
}

/**
 * Rebuilds contributions only for new blocks and blocks whose content hash or
 * file path changed, drops blocks no longer present, then resolves. Each call
 * builds its own `next` map from a snapshot of the cache and resolves that
 * map, so overlapping calls (a newer analysis request arriving while an older
 * one is still parsing) never mix block lists; the last call to finish
 * becomes the cache. Rejects (without touching the cache) when the parser
 * cannot initialize; per-block failures become `hasError` contributions.
 */
export async function updateProjectIndex(
  cache: ContributionCache,
  blocks: IndexBlock[],
  deps: UpdateIndexDeps = {},
): Promise<ProjectSymbolIndex> {
  const build = deps.build ?? buildBlockContribution;
  await (deps.init ?? initParser)();
  const previous = cache.byBlockId;
  const entries = await Promise.all(
    blocks.map(async (block): Promise<[string, BlockContribution]> => {
      const cached = previous.get(block.id);
      const reusable = cached && cached.contentHash === djb2(block.content) && cached.filePath === block.filePath;
      return [block.id, reusable ? cached : await build(block)];
    }),
  );
  const next = new Map(entries);
  cache.byBlockId = next;
  return resolveProjectIndex(next);
}
```

```ts
/**
 * @file analysisRequestHandler.ts
 * @description The analysis worker's request logic, kept out of the worker
 * file so it is unit-testable. Runs the regex analysis phases, then builds the
 * cross-file symbol index (nms4.2) as an optional extra on the result.
 *
 * Content-hash caching: if none of the block contents changed since the last
 * run (e.g. the user only moved blocks on the canvas), the cached result is
 * returned immediately without re-running anything.
 */
import { performRenpyAnalysis, performRouteAnalysis } from '@/hooks/useRenpyAnalysis';
import type { AnalysisBlock } from '@/hooks/useRenpyAnalysis';
import type { ProjectSymbolIndex, RenpyAnalysisResult } from '@/types';
import { formatErrorMessage } from '@/lib/formatErrorMessage';
import { performTranslationAnalysis } from '@/lib/renpyTranslationParser';
import { logger } from '@/lib/logger';
import { djb2 } from '@/lib/contentHash';
import { createContributionCache, updateProjectIndex, type ContributionCache } from '@/lib/tree-sitter/projectIndex';
import type { IndexBlock } from '@/lib/tree-sitter/blockContribution';

export interface AnalysisRequest {
  id: number;
  blocks: AnalysisBlock[];
}

export type AnalysisResponse =
  | { id: number; type: 'progress'; phase: string; percent: number }
  | { id: number; result: RenpyAnalysisResult }
  | { id: number; error: string };

export interface AnalysisHandlerDeps {
  updateIndex?: (cache: ContributionCache, blocks: IndexBlock[]) => Promise<ProjectSymbolIndex>;
  warn?: (message: string, error: unknown) => void;
}

interface BlockSignature {
  id: string;
  contentHash: number;
}

function computeSignatures(blocks: AnalysisBlock[]): BlockSignature[] {
  return blocks.map((b) => ({ id: b.id, contentHash: djb2(b.content) }));
}

function signaturesEqual(a: BlockSignature[], b: BlockSignature[]): boolean {
  if (a.length !== b.length) return false;
  for (let i = 0; i < a.length; i++) {
    if (a[i].id !== b[i].id || a[i].contentHash !== b[i].contentHash) return false;
  }
  return true;
}

/**
 * Creates a request handler with its own caches. Phases: regex parsing,
 * route graph, translations, symbol index. A symbol-index failure never
 * affects the regex result: `symbolIndex` is omitted and `indexError` set,
 * with one warning per handler lifetime.
 */
export function createAnalysisRequestHandler(deps: AnalysisHandlerDeps = {}) {
  const updateIndex = deps.updateIndex ?? updateProjectIndex;
  const warn = deps.warn ?? ((message: string, error: unknown) => logger.warn(message, error));
  const contributionCache = createContributionCache();
  let cachedSignatures: BlockSignature[] = [];
  let cachedResult: RenpyAnalysisResult | null = null;
  let warned = false;

  return async (request: AnalysisRequest, post: (message: AnalysisResponse) => void): Promise<void> => {
    const { id, blocks } = request;
    try {
      const signatures = computeSignatures(blocks);
      if (cachedResult && signaturesEqual(signatures, cachedSignatures)) {
        // Content unchanged (e.g. only canvas positions changed) — skip re-analysis.
        post({ id, result: cachedResult });
        return;
      }

      post({ id, type: 'progress', phase: 'Parsing scripts', percent: 10 });
      const result = performRenpyAnalysis(blocks);

      post({ id, type: 'progress', phase: 'Building route graph', percent: 60 });
      const routeData = performRouteAnalysis(blocks, result.labels, result.jumps);
      result.labelNodes = routeData.labelNodes;
      result.routeLinks = routeData.routeLinks;
      result.identifiedRoutes = routeData.identifiedRoutes;
      result.routesTruncated = routeData.routesTruncated;

      post({ id, type: 'progress', phase: 'Analyzing translations', percent: 80 });
      result.translationData = performTranslationAnalysis(blocks, result.dialogueLines, result.labels);

      post({ id, type: 'progress', phase: 'Indexing symbols', percent: 90 });
      try {
        result.symbolIndex = await updateIndex(
          contributionCache,
          blocks.map((b) => ({ id: b.id, filePath: b.filePath ?? '', content: b.content })),
        );
      } catch (error) {
        result.indexError = formatErrorMessage(error);
        if (!warned) {
          warned = true;
          warn('Symbol index build failed; regex analysis result is unaffected', error);
        }
      }

      post({ id, type: 'progress', phase: 'Finalizing', percent: 95 });
      cachedSignatures = signatures;
      cachedResult = result;
      post({ id, result });
    } catch (error) {
      post({ id, error: formatErrorMessage(error) });
    }
  };
}
```
